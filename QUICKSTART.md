# ⚡ Quick Start Guide

## Installation in 3 Steps

### Step 1: Download
```bash
wget https://your-url/beammp-complete-installer.tar.gz
tar -xzf beammp-complete-installer.tar.gz
cd beammp-complete-installer
```

### Step 2: Install
```bash
chmod +x install-beammp-complete.sh
./install-beammp-complete.sh
```

### Step 3: Access
```
http://YOUR_SERVER_IP:8081
```

---

## What You'll Need

1. **BeamMP Auth Key** - Get from https://beammp.com/keymaster
2. **Ubuntu Server** - 20.04, 22.04, or 24.04
3. **5 minutes** - Installation is automatic!

---

## Default Settings

- **Panel Port**: 8081
- **Server Port**: 30814
- **Max Players**: 8
- **Max Cars**: 4
- **Default Map**: Grid Map V2

All can be changed during installation! 🎮

---

## After Installation

### Access Panel
```
http://YOUR_SERVER_IP:8081
```

### Connect in Game
```
IP: YOUR_SERVER_IP

```

Just drag & drop .zip files in the panel! 📦
